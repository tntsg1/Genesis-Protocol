## 0. 一句话与卖点

**你设计一种生命的身体和本能，把它播种到异星，看它自己活、自己吃、自己变——直到它统治整颗星球，或者以你没想到的方式灭绝。**

商店页五个卖点（每条都要有对应的实机截图或 GIF）：

1. **设计本能，而不是指挥士兵**：用 IF-THEN 规则卡写出生命的行为，后代会遗传、变异，甚至演化出你没写过的组合。
2. **两千个发光生命同屏**：暗场显微镜下的荧光菌潮、捕食者撕开菌群、多细胞巨兽横穿培养皿。
3. **你是神，但只能动环境**：投营养、放寒潮、引洋流、喷信息素、陨石撞击——不能下命令，只能改变世界。
4. **每次灭绝都讲得清**：点开任意个体看它为什么这么做，回放族群崩溃的最后几分钟，用对照实验找出真正原因。
5. **把你的物种发给朋友**：创意工坊分享物种，与别人的物种在同一片生态里异步对决。

## 1. 核心循环（三层）

| 层 | 时间尺度 | 玩家在做什么 |
|---|---|---|
| 微观 | 秒级 | 观察、暂停、点开个体看决策、施放环境干预、中途基因注射 |
| 实验 | 分钟级 | 设计基因 → 写下预测 → 投放 → 观察 → 读报告 → 改一个变量再试 |
| 宏观 | 小时级 | 长局里跨纪元扩张、在研究草稿中挑新能力、选胜利路线；局间解锁新内容和资源加成 |

**防屏保铁律**（原策划第十章 10.2 节）：任何时刻屏幕上至少有一件“玩家可以做的事”——可施放的干预、待处理的研究发现、待回答的实验预测，或一个即将到来、已预告的环境事件。验收标准：试玩者不看说明时，能说出当前的目标，并主动提出下一轮实验的假设。

## 2. 游戏模式

### 2.1 战役

每关是一个**实验委托**：明确的目标 + 限定的基因预算 + 公开的环境条件。关卡里的威胁一律**事先告知**（例如“第 3 分钟会有捕食者进入”），不制造假涌现。每关有 3 颗星：完成目标 / 附加挑战 / 低预算完成。

最新的十章战役目录见 [CAMPAIGN.md](CAMPAIGN.md)；关卡编号调整以 [DECISIONS.md](DECISIONS.md) 中的最新决定为准。目录中的后续章节仍是设计草案，具体内容与解锁条件需逐关验证。

### 2.2 星球殖民长局（肉鸽，每局 60–90 分钟，可中途存档）

**开局**：在星图上从 3 颗候选星球中选 1 颗（显示星球类型、环境参数、原生霸主、可选胜利路线），从基因库里带上最多 3 个物种的初始设计（受基因预算限制）。

**星球结构**：5–7 个生态区组成一张连通图，区域之间有通道（狭窄水道、洋流、冰缝）。每个区域有自己的环境参数和原生物种。玩家先播种到 1 个区域，物种要靠自己扩散到其他区域。

**纪元节奏**：一局分为 6–8 个纪元，每个纪元约 10 分钟（1 倍速下）。纪元交替时：
- **研究草稿**：从 3 张随机研究里选 1 张——新性状、新规则卡、新模块、新干预，或者一次性强化。这是肉鸽的“构筑”来源。
- **星球事件预告**：下一纪元的季节变化、火山期、冰期等，提前公开。
- **结算面板**：各物种在各区域的生物量、谱系变化、新发现。

**胜利路线**（每颗星球提供其中 2–3 条，开局选定，中途可以改，但会损失进度）：

| 路线 | 条件 | 推动的设计方向 |
|---|---|---|
| 生物量霸权 | 你的物种在 ≥ 60% 区域生物量第一，并维持 1 个纪元 | 扩张、捕食、压制 |
| 生态共存 | 你的 3 个物种 + 至少 3 种原生物种同时存活，多样性指数 ≥ 阈值，维持 2 个纪元 | 平衡、食物链设计 |
| 撑过终末 | 最后一个纪元的星球终末灾变（全球冰封 / 超级火山 / 星耀）结束时，你的物种还活着 | 耐性、休眠、分散 |

**失败与重播种**：全部自有物种灭绝时，可以消耗大量生物质点，从基因库里重新播种（每局 2 次，可用永久加成提高）。次数用完后再灭绝，本局失败。失败也会结算研究点数。

### 2.3 沙盒 + 长期演化观测站

- **自由生态**：自定义地图尺寸、生态区布局、全部环境参数、任意物种（包括原生物种和 Boss），没有目标。
- **演化观测站**：后台无渲染高速快进（目标 ≥ 100 倍速），观察几百代的演化。提供谱系树、创新档案、关键事件时间线和事件回放。可以随时“取样”某个谱系，带回基因库。

### 2.4 创意工坊与异步对战

- **物种档案**：一个 `.genesis` 文件（JSON + 校验），包含性状、规则卡、模块蓝图、谱系名称和简介、缩略图。
- **分享**：上传到 Steam 创意工坊，订阅后进入基因库。
- **异步对决**：选一张标准竞技地图，自己的物种和对方的物种（加上标准原生生态）在本机模拟，比三项指标——存活时长、峰值生物量、区域占领。结果只在本机计算，不需要跨机器确定性。提供“擂台榜”：工坊物种按本机对决胜率排序（本地统计）。
- **防作弊**：读取档案时按当前版本的基因规则重新校验预算，超预算的档案拒绝加载。

## 3. 生命系统

### 3.1 性状（14 项，每项 1–5 级，花基因预算）

| 性状 | 好处 | 代价 |
|---|---|---|
| 体型 | 血量、可吞的猎物、抗冲击 | 代谢 ∝ 体型^0.75，繁殖投入大 |
| 运动 | 速度 | 运动能耗 ∝ 速度² |
| 视觉 | 感知半径 | 维持成本 |
| 化学感知 | 感知信号和尸体，可以绕过障碍 | 维持成本 |
| 外壳 | 减伤 | 质量 → 运动能耗上升 |
| 捕食器官 | 攻击 | 维持成本，植物性消化变差 |
| 消化取向 | 在“植食 ↔ 肉食”之间连续取值 | 两头不能兼顾 |
| 代谢效率 | 基础消耗下降 | 繁殖恢复变慢 |
| 繁殖策略 | 在“r（多而小）↔ K（少而强）”之间取值 | 后代初始能量 / 数量 |
| 寿命 | 活得更久 | 成熟变慢 |
| 温度耐受 | 适应区间的中心和宽度 | 区间越宽，维持成本越高 |
| 化学耐受 | 耐酸、耐辐射 | 维持成本 |
| 神经容量 | 规则卡槽位、阈值精度、记忆容量 | 维持成本高 |
| 突变率 | 演化速度 | 有害突变变多 |

### 3.2 规则卡（行为基因）

每张卡 = **条件**（1–2 个，AND 连接）+ **阈值** + **动作** + **优先级**（拖拽排序）。每个生物每次决策时，从上往下找到第一张条件全部满足的卡，执行它的动作；都不满足时，执行默认的“巡游”。卡槽数量由神经容量决定（3–8 张）。

**条件（初始约 18 种，研究后增加）**：能量高于/低于 X；血量低于 X；视野内有食物、尸体、同类、异种、比我强的、比我弱的生物；信号 A/B 浓度高于 X；刚受到攻击；记忆中有食物点或危险方向；周围同类数量高于/低于 X；温度不适；年龄大于 X；处于 N 号模块受损状态（多细胞）。

**动作（初始约 14 种）**：趋向/远离目标；进食；攻击；逃跑；休眠（极低代谢）；分裂；释放信号 A/B；跟随同类；聚集；记住当前位置；返回记忆点；巡游；守卫（停在原地，打靠近的目标）。

**规则卡的遗传和变异**：
- 阈值漂移（最常见）
- 改变卡的顺序
- 复制一张卡（受槽位限制）
- 删除一张卡
- 替换条件或动作，只能在已解锁的原语里换——模拟里没有的原语，生物不可能凭空学会

**编辑器**：玩家看到的是可读的卡片；底层是可执行的数据结构，执行器编译成字节码，两者一一对应。每个生物在被检视时，可以列出“这一刻哪张卡触发了、上面哪几张卡因为什么条件不满足”。

### 3.3 能量账本（守恒是底线）

```
下一步储能 = 当前储能 + 吸收量 × 消化效率
          − 基础代谢 − 运动 − 感知/神经维持 − 攻击/信号成本 − 繁殖投入
```

- 吸收量不能超过食物或猎物的剩余能量；尸体留下能量，分解者和环境会逐渐把它变回营养。
- 环境里的营养只能来自两处：外部能量输入（光照、热泉），以及分解物回流。
- 每个 tick 都校验全局能量平衡（容许耗散），一旦对不上，测试直接失败。

### 3.4 信号场与记忆

- 信号 A、B 存在于覆盖全地图的网格中（每格 16 px），会扩散、衰减，也会被洋流带走。
- 每个物种对同一个信号的反应由它自己的规则卡决定，所以捕食者可以写一张“追踪信号 A”的卡来利用你的菌群。
- 短期记忆：1–4 个槽位，记住食物点、危险方向或失败的追击，会随时间过期。

### 3.5 物种和谱系

- 个体的基因组和亲代的差异超过阈值时，标记为新谱系（分支），自动命名，玩家可以改名。
- 谱系树记录分支时间、关键突变和当时的环境，支持“取样回基因库”。

## 4. 多细胞

### 4.1 模块编辑器

在六边形格子上摆放 3–12 个模块，模块之间必须连通。整只生物共享一个基因组、一个决策控制器、一个能量账户。

| 模块 | 功能 |
|---|---|
| 核心 | 必须有；储存基因和控制器，被毁就死 |
| 鞭毛推进 | 推力，有方向 |
| 纤毛 | 低速转向，耗能低 |
| 甲板 | 减伤，有朝向 |
| 颚 | 前向攻击 |
| 刺丝 | 被动反伤 |
| 储能囊 | 能量上限 |
| 感光眼 | 视觉扇区 |
| 化学须 | 化学感知 |
| 信号腺 | 释放信号 |
| 光合板 | 有光照时产能（只在亮区有效） |
| 再生芽 | 慢慢修复受损模块 |

**物理**：刚体，由模块质量、推力和位置算出速度与转向。模块会单独受损失效，失效后功能消失，并影响平衡（比如一侧推进坏了，就会原地打转）。不做柔体。

### 4.2 稀有的自然多细胞化

单细胞同时满足以下条件时，有小概率出现“粘连”突变，形成 2–4 个模块的简单群体：持续聚集（空间接近 + 持续时间 + 与随机基线相比显著）、有同类识别、处于高捕食压力下。这是“研究发现”中的大事件，满足条件就能复现，不是脚本。

## 5. 生态与星球

### 5.1 星球类型（6 种，程序生成布局）

| 星球 | 环境特点 | 原生霸主（Boss） |
|---|---|---|
| 热泉海床 | 热泉提供局部能量，温差大 | 熔岩滤食兽 |
| 冰封海 | 低温，冰缝通道，营养少 | 冰下潜猎者 |
| 酸性沼泽 | 酸度高，营养丰富，腐殖分解快 | 菌毯意识 |
| 潮汐盆地 | 周期性洋流和干涸 | 潮汐巨噬者 |
| 无光洞穴 | 没有光照，只有化学能，视觉无用 | 盲眼群猎 |
| 晶体荒原 | 高辐射，突变率翻倍 | 晶簇吞噬体 |

战役星球与终局地点以最新战役目录为准；长局的开放时机仍待确定。

### 5.2 原生物种生成

按星球环境，用和玩家相同的基因系统程序生成 4–8 种原生物种，覆盖生产者、采集者、捕食者、分解者几种生态位，并让它们在后台预先演化 50 代，作为开局状态。原生物种在游戏中也会继续演化。Boss 物种是手工设计的多细胞生物，有专属模块（例如超大颚、信号干扰腺），但同样遵守能量守恒——它们也会饿死。

### 5.3 环境参数

温度、光照、营养再生速度、洋流方向和强度、酸度、辐射。季节和纪元事件会改变这些参数，所有变化提前预告。

## 6. 环境干预与资源

**生物质点**：按你所有物种的总生物量持续产出。活得越好，可以做的事越多。
**研究发现**：达成可测量的创新事件时奖励（见第 7 节），能换取稀有的强力干预。

| 干预 | 效果 | 类型 |
|---|---|---|
| 营养投放 | 在指定位置撒营养 | 常规 |
| 隔离膜 | 一段临时屏障 | 常规 |
| 局部升温/降温 | 一片区域的温度改变 | 常规 |
| 洋流引导 | 临时改变局部洋流方向 | 常规 |
| 信息素喷洒 | 释放信号 A/B（会被所有物种感知） | 常规 |
| 基因注射 | 对选中的谱系改 1 项性状或 1 张卡（之后的后代继承） | 常规，冷却长 |
| 定向播种 | 把基因库里的物种投到新区域 | 常规，贵 |
| 重播种 | 灭绝后从基因库重生 | 每局有次数限制 |
| 陨石撞击 | 毁灭一片区域，留下大量营养 | 稀有 |
| 大冰期 | 全球降温一个纪元 | 稀有 |
| 突变风暴 | 一片区域突变率 ×5 | 稀有 |
| 生命之雨 | 全图营养大爆发 | 稀有 |

**不能做的事**：直接移动、命令或者杀死某个个体。

## 7. 研究发现（可测量的创新事件）

每个事件都有严格的统计定义，防止“偶然凑在一起”被误判成新行为：

- 首次在新区域建立种群（≥ 20 个体并维持 60 秒）
- 新谱系分支
- 稳定群聚：空间聚集度高于随机基线 2σ 以上，并持续 ≥ 90 秒
- 新食物链：你的捕食物种 ≥ 50% 的能量来自你的另一个物种
- 自发的信号利用：某个谱系通过突变获得了“对信号 X 有反应”的卡，并且因此提高了存活率（与对照组比较）
- 自然多细胞化（见 4.2）
- 存活 100 / 500 / 1000 代

每个发现进入**创新档案**，可以回放发现的那一刻。

## 8. 可解释性（让失败可以学）

1. **个体检视**：能量、血量、年龄、所在环境、当前目标、最近感知、触发的规则卡，以及上面哪几张卡没触发、为什么。
2. **死因统计**：饥饿、被捕食（被谁）、衰老、温度、酸度、被挤死，按时间画成曲线。
3. **实验报告**：严格区分**事实**（“62% 死于饥饿”）和**假设**（“可能是运动耗能过高”，标注为待验证）。
4. **对照实验**：一键复制当前方案，只改 1 个变量，用 5 个随机种子并行快速模拟，比较均值和波动。
5. **回放**：保存固定时间间隔的快照 + 随机种子 + 玩家干预记录。同一版本下，从任意快照重新模拟，可以精确回放。跨版本只提供统计回顾。

## 9. 美术（2026-10-27 定案，见 DECISIONS.md 后几节）

**第一印象**（用户原话，所有美术验收以此为准）：这不是一堆会移动的程序，而是一个真实存在的微观世界。打开游戏，玩家看到一个培养皿。营养粒子悬浮在液体中，光线穿过水体，半透明的细胞缓慢游动。

**硬性要求**：明亮、开朗、快乐、轻松；纯 2D 扁平（不做高光、投影、球面明暗）；不强加眼睛等拟人化；捕食不能有杀戮感。已被否决：暗场荧光，阳光果冻，萌系大眼，水彩。

### 9.1 培养皿（shaders/dish.gdshader）

- 圆形玻璃皿放在浅灰蓝色的实验台上，皿边会反光；模拟边界也是圆形。
- 清透的水，中央有显微镜灯光的亮区，向皿边逐渐变凉；水里有柔和的波光和斜向光带。
- 悬浮粒子分三层深度，随镜头产生视差：远处是细小微尘，中间是绿色藻团（营养多的地方藻团就多，食物在哪一眼就能看出来），近处是焦外光斑。
- 皿边内侧长着浅色礁石和粉彩珊瑚。

### 9.2 生物（shaders/organism.gdshader）

- 半透明粉彩填充 + 固定像素宽度的干净描边 + 同色柔光。
- **基因决定外形**：速度 → 细长身体、纤毛环、长鞭毛；感知 → 前端眼点；外壳 → 分段厚壳；攻击 → 口刺，捕食者带颚和触须；繁殖 → 圆胖；代谢效率 → 储能细胞器更多；群居 → 周身信号点。
- **游动**：水本身在流动；一推一滑的游泳节奏，转向有惯性；身体左右轻摆，冲刺时拉长，身后留下淡淡的水痕。
- **LOD**：远处是柔和的色点，中距离画身体、描边和细胞核，近处加纤毛、细胞器、触须、壳板。同屏约 2000 只。
- 多细胞：整体包膜外围一圈纤毛，模块各有部件（核心、鞭毛、甲板、颚、眼点、储能泡）。
- 概念图（深蓝发光版）只作为细节、三层视角、关键动画和 UI 布局的参考，底色不采用。

## 13. UI/UX（对照人机交互八条法则）

1. **一致性**：所有编辑器用同一套拖拽、悬停说明和撤销逻辑。
2. **快捷键**：空格暂停，1/2/3/4 切换速度，Tab 切分析模式，Q/W/E/R 对应常用干预，Ctrl+Z 撤销编辑。
3. **反馈**：每次施放干预都有画面、声音和数字反馈；规则卡触发时，检视面板里对应的卡会高亮闪烁。
4. **完成提示**：发现、纪元结算、关卡结算都有明确的完成画面。
5. **防错纠错**：基因预算超支时无法投放并指出原因；规则卡出现“永远不会触发”的情况时会给出警告。
6. **可取消**：干预在瞄准阶段可以右键取消；投放前的所有编辑都能撤销。
7. **用户掌控**：随时暂停、变速、存档；长局的研究草稿可以“搁置”（不选）。
8. **减轻记忆**：基因库会显示每个物种上次的战绩；检视面板直接显示数值，不用玩家记。

## 14. 技术架构

| 层 | 实现 | 职责 |
|---|---|---|
| SimCore | C++ GDExtension（godot-cpp） | 个体用 SoA 数组存储；均匀网格做邻居查询；规则字节码执行；能量账本；繁殖、变异、死亡；信号场扩散；固定 15 Hz tick；种子化随机数 |
| MultiCell | C++ | 模块连接图、刚体推力和转向、模块损伤 |
| Ecology | GDScript + C++ 接口 | 生态区、环境参数、季节、事件、原生物种生成 |
| Tracker | C++ 统计 + GDScript 展示 | 种群曲线、死因、谱系树、创新事件检测、快照 |
| Game | GDScript | 战役、长局、研究草稿、干预、存档、成长 |
| Render | MultiMesh + 着色器 | 只读 SimCore 导出的缓冲区，60 FPS 插值显示 |
| UI | Godot Control | 编辑器、面板、终端 |
| Steam | GodotSteam | 成就、云存档、创意工坊 |

**性能目标**（GTX 1060 / 4 核 CPU 级别）：
- 2000 个单细胞 + 40 只多细胞，1 倍速 60 FPS，8 倍速不低于 30 FPS
- 观测站无渲染快进 ≥ 100 倍速
- 2 小时连续运行内存不持续增长

**工具**：
- 无渲染批量平衡器：多种子、多密度、多环境批量模拟，输出存活代数、能量平衡、多样性、必胜策略检测。
- 能量守恒断言测试、确定性回放测试。
- 截图工具：不抢鼠标、不抢焦点，遵守已有的测试规范；测试不得读写真实存档。

**存档**：`user://` 下 JSON + 二进制快照，保留滚动备份；云存档同步这个目录。

## 18. 发布前验收清单

1. 规则可以解释：能量、资源、死亡、繁殖都有清楚的来源。
2. 基因有因果影响：在重复对照实验中，改关键卡会造成显著差异。
3. 存在多样性：不会有一套没有代价的方案统治所有环境（由平衡器验证）。
4. 可玩性成立：试玩者主动提出下一轮的假设。
5. 意外有依据：重要的新行为都能追溯到现有机制。
6. 性能达标（见第 14 节）。
7. 数据可靠：基因档案、谱系、报告都能保存、加载、复核。
8. 战役全部正式关卡、各正式星球和胜利路线都至少被打通一次。
9. Steam 功能全部可用，云存档冲突处理正确。

## 19. 主要风险与对策

| 风险 | 对策 |
|---|---|
| 变成屏保 | 三层循环 + 防屏保铁律 + 干预 + 研究草稿；M4 门槛把关 |
| 演化没有新意 | 规则卡可以复制、删除、换序、替换；信号和记忆；创新事件；自然多细胞化 |
| 生态无意义地崩溃 / 出现万能基因 | 能量守恒；空间异质性；批量平衡器 |
| 多细胞开发量爆炸 | 共享控制器 + 刚性模块；分 A/B/C 三阶段验收 |
| 玩家看不懂失败 | 个体检视、死因统计、事实和假设分离、对照实验、回放 |
| 两千只的性能 | C++ SimCore + MultiMesh + LOD；M0 先验证 |
| 荧光美术达不到商店页水准 | M0 先出截图给用户确认，再批量制作 |
| 永久加成破坏平衡 | 只加资源、有上限，不加生物属性 |
| 宣传过度承诺 | 宣传口径统一为“在规则内演化出新的组合和策略”，不承诺无限开放式进化；不宣传“三千代” |
